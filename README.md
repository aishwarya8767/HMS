🏥 Hospital Website – WeCare
📖 Overview

This project is a responsive hospital website built using HTML, CSS, and JavaScript (jQuery).
It is designed to provide users with essential information about hospital facilities, services, and appointments.
The website is modern, user-friendly, and visually appealing — suitable for hospitals, clinics, or medical institutions.

✨ Features

🏠 Home Section – Attractive hero banner introducing hospital services

🏥 About Section – Information about emergency, ambulance, and check-up services

⚙️ Facility Section – Showcases hospital facilities using image gallery

💬 Review Section – Displays patient feedback

📊 Counter Section – Highlights hospital statistics (beds, patients, staff)

📞 Contact Form – Book appointments directly from the site

📰 Blog/Post Section – Displays latest updates or news

🔗 Footer Section – Quick links and social media handles

📱 Fully Responsive – Works seamlessly on desktop and mobile devices

🛠️ Technologies Used

HTML5 – Markup structure

CSS3 – Styling and responsiveness

JavaScript (jQuery) – Dynamic UI interactions

Bootstrap 5 – Layout and responsive grid system

Font Awesome – Icons

AOS (Animate On Scroll) – Scroll animations

Magnific Popup – Lightbox gallery for facilities
